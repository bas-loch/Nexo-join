# Photos à déposer ici

Voir `src/data/images.ts` pour la liste exacte des noms de fichiers
attendus (hero.jpg, terrasse-01.jpg, menu-page-01.jpg à
menu-page-04.jpg, logo.png, etc.). Il suffit de déposer chaque fichier
sous le nom indiqué : le site l'affiche automatiquement à la place du
bloc de substitution, sans modification de code.
